============================================================
  汉化发布站 —— 文件夹放什么
  每个文件夹是干什么的、东西该往哪放，看这一份就够
============================================================


【一句话版】

  日常你只会用到这三个地方：

    source/_posts/     放漫画作品（每部作品一个 .md 文件）
    source/files/      放小说文件（TXT / EPUB）
    source/_data/      加小说时登记一下（novels.yml）

  改站名、密码、联系方式 → 只改根目录的「我的设置.yml」

  其他文件夹基本不用碰。


============================================================
  目录总览（★ = 你经常会动的，× = 不要动的）
============================================================

│
├─ source/                 ── 网站内容全在这里 ──
│   │
│   ├─ _posts/             ★★ 作品页：每部漫画一个文件
│   │                          公告也放这里（分类写「公告」）
│   │
│   ├─ _data/              ★ 小说下载的登记表
│   │   └─ novels.yml          加小说时改这个
│   │
│   ├─ files/              ★ 小说的 TXT / EPUB 文件放这里
│   │
│   ├─ img/                ── 图片 ──
│   │   └─ cover/          ★ 作品封面图放这里
│   │
│   ├─ index.md            首页（最近更新 / 完结合集 两个栏目）
│   ├─ novels/index.md     小说下载页（粉丝在这输密码下载）
│   ├─ guide/index.md      ★ 获取须知页 ── 解压密码写在这
│   ├─ report/index.md     ★ 失效反馈页 ── 你的邮箱写在这

│   ├─ tutorial/index.md   官网购买教程
│   ├─ tags/               × 标签总览页（自动生成，别管）
│   ├─ categories/         × 分类总览页（自动生成，别管）
│   ├─ css/                × 自定义样式
│   └─ js/                 × 前端脚本（下载按钮、年龄门等）
│
├─ scripts/                × 构建脚本（自定义标签、设置替换、年龄门）
├─ 工具/                   × 辅助脚本（改设置、修路径、打包）
├─ .github/                × 自动部署配置（提交后自动发布网站）
│
├─ _config.yml             × 站点配置（站名署名已由「我的设置.yml」接管）
├─ _config.butterfly.yml   × 外观配置（社交图标/主题色已由「我的设置.yml」接管）
├─ package.json            × 依赖清单
├─ package-lock.json       × 依赖版本锁定
├─ node_modules/           × 依赖本体（几百 MB，GitHub 会自动装，别传）
├─ public/                 × 构建产物（每次自动生成，别改）
├─ db.json                 × 缓存（每次自动重建）
└─ *.md 文档               说明文档（就是你现在看的这类）


============================================================
  逐个文件夹说明
============================================================

■ source/_posts/  —— 作品页（最常用）

  每部作品一个 .md 文件，文件名就是网址。
  例：dhldxn.md  →  https://你的站/dhldxn/

  放什么：
    · 漫画作品（categories 写「漫画」）
    · 小说作品（categories 写「小说」）—— 如果要给小说做介绍页
    · 公告（categories 写「公告」）—— 公告不会出现在作品列表里

  注意：
    · 作品页里不写 updated 字段，网站按「文件最后修改时间」自动置顶
    · 更新一话后只要保存这个文件，它就会自动排到最前面


■ source/files/  —— 小说文件

  放什么：小说的 TXT、EPUB 文件本体。
  例：dhldxn.txt、dhldxn.epub

  放完还要去 source/_data/novels.yml 里登记一条，
  粉丝才能在「小说」页看到它。


■ source/_data/  —— 小说登记表

  novels.yml：小说的书名、简介、封面、文件路径都写在这。
  加一本小说 = 文件丢进 source/files/ + 在这里加一条。

  它顶部的 password_hash 是小说下载密码（由「我的设置.yml」的密码自动算出来，
  一般不用手改）。


■ source/img/cover/  —— 作品封面

  放什么：每个作品的封面图，文件名和作品文件对应。
  例：作品是 dhldxn.md，封面就叫 dhldxn.jpg

  建议：竖图，宽高比 3:4（比如 600×800），JPG 格式。
  不写封面也能用，网站会自动生成一张渐变色的替代封面。


■ source/guide/、about/、report/、expose/、relink/  —— 页面文案

  这些都是「页面」，改文案直接编辑里面的 index.md：

    guide/    获取须知 ── 解压密码（用 {% copy %%密码%% %}，会自动填成你的密码）
    report/   失效反馈 ── 粉丝怎么联系你（邮箱）
    about/    关于本站 ── 你的联系方式、免责声明
    expose/   倒卖曝光墙 ── 记录倒卖者（有模板，照着填）
    relink/   补链合集 ── 网盘链接失效后补的新链接挂在这里

  ★ 这些页面里的 %%密码%% %%邮箱%% %%微博%% 是占位符，
    会自动替换成「我的设置.yml」里填的内容，不用手改。


■ source/js/ 和 source/css/  —— 前端脚本与样式（一般不动）

  js/hb-download.js    网盘下载按钮：点开显示链接 + 复制提取码
  js/hb-novel.js       小说下载：输密码解锁
  js/hb-agegate.js     18+ 年龄确认门
  js/hb-effects.js     页面特效
  css/custom.css       自定义样式

  改这些会影响网站功能，拿不准就别动。


■ scripts/  —— 构建脚本（不要动）

  tags.js             自定义标签（{% dl %} {% novels %} 等）
  render-settings.js  把 %%密码%% 这类占位符替换成你的设置
  agegate-inject.js   给每个页面注入 18+ 年龄门

  动这里可能让网站构建失败。


■ 工具/  —— 辅助脚本（不要动）

  应用设置.py      把「我的设置.yml」应用到处（构建时自动跑）
  mtime_sync.py    记录/还原文件修改时间（关系到「最近更新」排序）
  适配子路径.py    让网站能在 GitHub 子路径下正常显示
  打包给朋友.py    把整站打包成 zip（站主用）


■ .github/  —— 自动部署（不要动）

  你每次提交（Commit）后，GitHub 会照着这里的配置自动重新发布网站。
  不用管它，但也没必要删。


============================================================
  ★ 快速对照表：我要做 X，去哪个文件夹
============================================================

  加一部漫画           → source/_posts/ 新建 .md
                        封面丢进 source/img/cover/

  作品更新一话         → 编辑 source/_posts/ 里那个 .md
                        （保存后自动置顶）

  加一本小说           → 文件丢进 source/files/
                        + 在 source/_data/novels.yml 加一条

  网盘链接挂了要补链   → source/relink/index.md 里加一条记录
                        （记得同步改作品页里的链接）

  记录倒卖者           → source/expose/index.md

  改站名/署名          → 我的设置.yml

  改解压密码           → 我的设置.yml（小说下载密码会一起变）

  改联系方式           → 我的设置.yml（微博、邮箱）

  换主题色             → 我的设置.yml

  改首页栏目文字       → source/index.md

  改「获取须知」内容   → source/guide/index.md


============================================================
  命名规则（容易踩的坑）
============================================================

  1. 文件名用英文字母、数字、短横线，别用空格和中文
     —— 文件名会出现在网址里，英文更干净、更不容易出错
     例：达哈伦的修女.md  →  建议写成  dhldxn.md

  2. 不要用下划线 _ 开头
     —— 下划线开头的文件会被网站忽略，不会发布

  3. 写配置时，冒号后面要留一个空格
     对： title: 我的汉化站
     错： title:我的汉化站

  4. 封面图和作品文件用同一个名字，好记也不容易错


============================================================
  千万不要动的文件夹
============================================================

  scripts/                  构建脚本
  工具/                     辅助脚本
  .github/                  自动部署配置
  node_modules/             依赖本体（几百 MB，GitHub 会自动装）
  public/                   构建产物（每次自动生成）
  db.json                   缓存（每次自动重建）
  package.json              依赖清单
  package-lock.json         依赖版本锁定

  动了这些，网站可能直接构建失败、或者页面功能坏掉。
  确实需要改功能，找站主或懂技术的人帮忙。
