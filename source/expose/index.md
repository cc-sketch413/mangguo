本站所有汉化作品**永久免费**。如果有人在任何平台售卖本站在免费发布的作品，那就是**倒卖**。

## 为什么建这面墙

汉化是个人无偿劳动，图的是同好能一起看到喜欢的作品。倒卖者把免费的东西拿去二次收费，既伤害译者，也坑了不明真相、多花了冤枉钱的粉丝。

这面墙把倒卖者公开出来，让大家看清是谁在赚这份黑心钱，也让后来的人少上几次当。

{% tip danger %}
**本站作品永远免费。** 如果你在别处花钱买到了本站的汉化，说明你被倒卖了。请到下方评论区或[关于本站](/about/)告诉我，我会把对方挂到名单里。
{% endtip %}

## 发现倒卖，怎么举报

举报时请尽量提供以下信息，越全越容易锁定：

```
平台：       （淘宝 / 闲鱼 / 拼多多 / 微信 / QQ群 / 贴吧 …）
店铺或账号名：
链接或截图：
售卖的作品名：
```

截图可以发到[关于本站](/about/)页面留下的邮箱，或在本页评论区贴出。
