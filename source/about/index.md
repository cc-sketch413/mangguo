## 这是一个什么站

个人汉化作品的发布站。做的是**漫画和小说**的中文化，全部免费发布，供同好交流。

做汉化纯粹是兴趣。看到喜欢的作品没有中文，就自己动手 —— 慢，但总比没有好。

{% worklist %}

## 关注更新

新作发布和补档通知都会发在「公告」分类里。想第一时间知道，用下面任意一种方式：

{% tip info %}
- **RSS 订阅**：[点这里](/atom.xml) —— 推荐，不用注册任何账号，新文章自动推送
- 微博 / 交流群：见页面右侧或下方的社交图标
- 收藏本站，不定期来看看「公告」
{% endtip %}

## 免责声明

本站所有汉化作品仅供**个人学习、交流与研究**使用，**禁止任何形式的商业用途与贩卖**。

- 所有作品著作权归原作者及出版方所有
- 本站不存储、不制作任何官方资源，仅提供个人汉化成果
- 请尽量支持原作者与正版，喜欢的话去买一份

## 本站构成

| 项目 | 说明 |
|---|---|
| 框架 | Hexo（静态站点生成器） |
| 主题 | Butterfly（在此基础上做了自定义组件） |
| 托管 | 静态托管，无后端、无数据库 |
| 评论 | 第三方评论系统，数据不在本站 |

本站不使用任何追踪用户行为的脚本，不收集访客信息。

## 更新说明

每次作品更新都会写进该作品页的「更新记录」，全站层面的公告（新作发布、补档通知、密码变更）会单独发在「公告」分类。

**关于提取码和解压密码**：见[获取须知](/guide/)。密码如果变更，会在公告里通知。
