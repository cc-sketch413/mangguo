## 怎么获取

{% tip info %}
本站作品全部**免费发布**。点进任意作品页 → 拉到「下载」区域 → 点网盘链接 → 转存到自己网盘 → 下载。
{% endtip %}

1. 在顶部导航的**作品库**里找到你要的作品（可以按漫画 / 小说分类，或直接搜索）
2. 点进作品页，确认简介和汉化进度是你想要的
3. 拉到页面下方的**下载**区域，点对应的网盘链接

作品页上都会标注**当前汉化到第几话**，没写到的就是还没做完，不用催。

## 网盘使用

- **提取码**：直接写在链接按钮下方，不用问我
- **转存后下载**：建议先「转存到我的网盘」再下载，这样即使原链接失效你手上还有一份，也方便以后补档
- **解压密码**：统一是下面这个（**大写需要注意**）

{% tip ok %}
解压密码：`hxfabuzhan`
{% endtip %}

如果密码不对，先确认是不是把空格复制进去了，再检查压缩包是不是下载完整。

## 推荐阅读方式

### 漫画

| 平台 | 推荐工具 | 说明 |
|---|---|---|
| Windows | CDisplayEx、Honeyview | 支持压缩包直接翻页 |
| Android | Tachiyomi、Perfect Viewer | 本地漫画库，自动记录进度 |
| iOS | Panels、可达漫画 | |
| 电纸书 | Kindle Comic Converter | 转成 epub/mobi 后阅读体验最好 |

漫画图片统一是 **PNG 或 JPG**，按话打包成 zip，直接改名成 `.cbz` 也能被多数阅读器识别。

### 小说

提供 **TXT / EPUB** 两种格式。EPUB 带目录，优先选它；TXT 方便喂给各种阅读 App 和 TTS。

## 常见问题

**Q：链接失效了怎么办？**
到[失效反馈](/report/)页面按格式留言，我会尽快补档。留言时请写清**作品名 + 哪一话 + 哪个网盘**。

**Q：会做 XX 作品吗？**
欢迎许愿，但排期看我自己有没有兴趣和时间，不保证接。

**Q：可以转载我的汉化吗？**
{% tip warn %}
可以转载，但请遵守三条：
1. 注明译者与本站链接
2. **不要用于任何商业用途**，不要上传到收费平台或需要付费解锁的网盘
3. 不要二次修改后署名成自己的
{% endtip %}

**Q：汉化质量怎么样？**
个人汉化，不是专业团队。会有错译和错字，欢迎提，见[失效反馈](/report/)页面。

**Q：为什么有些作品只有网盘没有在线阅读？**
图片量大或排版复杂的作品，网页阅读体验差，只提供打包下载。小说如果章节少，可能会放一部分在页面里供试读。
