链接挂了、密码错了、文件损坏、发现错译 —— 都从这里反馈。

{% tip info %}
链接补好后，新链接会统一公示在 **[补链合集](/relink/)** 页，失效了先去那边看看，可能已经补好了。
{% endtip %}

{% tip danger %}
**发现倒卖？** 这不是链接问题，请直接到[倒卖曝光墙](/expose/)举报，那里有专门的举报格式。
{% endtip %}

## 反馈格式

{% tip warn %}
为了能快速定位，请**按这个格式**留言。信息不全的我只能回头问你，一来一回很慢。
{% endtip %}

```
作品名：
问题类型：（链接失效 / 提取码错误 / 解压失败 / 文件损坏 / 错译错字）
哪个网盘：（百度 / 蓝奏 / MEGA）
哪一话或第几页：
具体情况：
```

举个合格的例子：

```
作品名：（填具体作品名）
问题类型：链接失效
哪个网盘：百度
哪一话或第几页：（整体）
具体情况：点进去提示"分享文件已被取消"，蓝奏那个还能用
```

## 各类问题的处理方式

| 问题 | 我会怎么做 | 大概需要多久 |
|---|---|---|
| 链接失效 | 重新打包上传，在本页回复补档链接 | 一两天内 |
| 提取码错误 | 核对后更正作品页 | 尽快 |
| 解压失败 | 说明用的解压软件，可能是编码问题；必要时换压缩格式重传 | 一到三天 |
| 文件损坏 / 缺页 | 核对源文件后重传 | 一到三天 |
| 错译 / 错字 | 确认后在下一次更新里一并修正，并在作品页更新记录注明 | 随下次更新 |

{% tip info %}
**补档说明**：链接失效的补档会在本页留言里回复，不会单独发公告。
如果你只是想要某部作品的文件，可以先看看有没有人已经反馈过同一个问题。
{% endtip %}

## 留言

用下面的评论区反馈即可。**不需要注册账号**，填个昵称就能发。

如果评论区用不了（比如加载不出来），可以到 [关于本站](/about/) 页面通过邮箱联系我。

{% tip ok %}
留言时带上**作品名**，比"楼主链接挂了"这种能快十倍解决。
{% endtip %}

## 请不要这样反馈

- ❌「链接挂了」 —— 哪个作品？哪个网盘？
- ❌ 在评论区发网盘链接求资源 —— 请走作品页的正式链接
- ❌ 把作品文件重新上传到自己的网盘分享 —— 请在原作品页留言，我统一补档
- ❌ 催更 —— 排期看我的时间，催也不快
