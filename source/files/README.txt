【小说文件放这里】

把小说做成 zip 压缩包，复制到本目录（source/files/），
然后在 source/_data/novels.yml 里照抄一条记录，填上文件名和密码哈希即可。

一本小说分好几卷？就每卷打一个 zip，登记时在 files 里写多条：
    达哈伦的修女-第1卷.zip  ->  dhldxn-vol1.zip
    达哈伦的修女-第2卷.zip  ->  dhldxn-vol2.zip
    达哈伦的修女-第3卷.zip  ->  dhldxn-vol3.zip

建议文件名用英文或拼音，因为网址里会带文件名，英文/拼音更干净、更不容易出错。

★ 强烈建议：打包 zip 时给 zip 加「压缩密码」，密码就设成和这本小说的
  下载密码一样 —— 这样就算文件被人直接下载，没密码也解不开。
  （页面上的密码只是"门帘"，zip 自带的压缩密码才是真保护。）

放好之后双击站点目录下的「一键发布.bat」，网站就会自动更新。
