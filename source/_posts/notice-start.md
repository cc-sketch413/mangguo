本站开张了。简单说明几件事，**第一次来的朋友看完这一篇就够了**。

<!-- more -->

## 这里是做什么的

发布我个人的汉化作品，主要是**漫画和小说**。全部免费，不做任何收费或引流。

所有内容都按作品分页，页内下方就是下载地址。

## 怎么获取

1. 进[作品库](/library/)，按漫画 / 小说分类找，或者直接搜作品名
2. 点开作品页，确认汉化进度是你想要的
3. 拉到页面下方「**下载**」区域，点网盘链接

详细的网盘使用方法、解压密码、推荐阅读器，都在[获取须知](/guide/)页面。

{% tip warn %}
**解压密码统一是 `hxfabuzhan`**，写在每个作品的下载按钮下方也有。请不要在评论里问密码，先看须知页。
{% endtip %}

## 更新怎么通知

- **RSS 订阅**：[/atom.xml](/atom.xml) —— 推荐，不用注册账号，有新作品自动推送
- 新作发布、补档通知、密码变更都会发在「**公告**」分类里
- 微博会同步吆喝一声

## 关于催更和许愿

许愿欢迎，在[关于本站](/about/)留言就行，但我只做自己有兴趣的作品，不保证接。

催更就……看缘分了。业余时间做的，快不了。

## 关于转载

可以转载，但请**注明译者和本站链接**，不要用于商业用途，也不要二次修改后署名成自己的。

具体规则在[获取须知](/guide/)里。

## 关于倒卖

本站作品**永久免费**。任何地方出现的收费售卖，都是倒卖。

{% tip danger %}
发现倒卖请到[倒卖曝光墙](/expose/)举报，我会把对方挂出来公开。漫画图片已嵌入水印，方便追溯；花钱买到的朋友请直接退款并举报。
{% endtip %}

{% tip ok %}
有任何问题（链接失效、错译、解压失败），请到[失效反馈](/report/)页面按格式留言。
带上作品名，能快十倍解决。
{% endtip %}
